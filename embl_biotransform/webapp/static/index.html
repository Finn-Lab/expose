Analyses (tick several to compare them)

MGnify API v2, pipeline v6 assembly analyses. Taxonomy comes from the contig assignments, which is what lets each enzyme be tied to the organism carrying it.

Downloaded analyses (kept between runs)

Reads-based profiles from bioSIFTR. Run the pipeline yourself, then point EXPOSE at its --outdir. Its lineages are GTDB; resolving them to NCBI lets them match references by taxon id.

2 Reference associations

Curated per-gene and per-microbe statements bundled with the project.

Columns: entity_type (gene|microbe), entity_id, reaction_class; optional alt_ids, entity_name, chebi_substrate, source, evidence.

Built assays (kept between runs)

Builds associations from ChEMBL Bacterial Biotransformation assays. Gene assays give Tier 1 references (with InterPro/Pfam ids), microbe assays Tier 2, and community assays become measured outcomes shown on the grid.

3 Options

A profile reports every level of its lineage. Anything coarser than genus says a group is present, which cannot support a claim about a named organism, so those rows are excluded by default.

Which biotransformations could this community carry out?

Choose a metagenome sample and a set of reference associations, then run the analysis. Each predicted reaction class comes with the evidence behind it:

  • Tier 1 the enzyme itself was detected in the sample's functional annotation (strong).
  • Tier 2 a microbe known to perform the reaction is present, but its enzyme wasn't confirmed (weaker).
